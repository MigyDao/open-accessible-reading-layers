# Code of Conduct

Open Accessible Reading Layers exists to improve access to reading and information. Participation should reflect that purpose.

## Expected behavior

Contributors and participants are expected to:

- communicate respectfully and in good faith;
- welcome people with different disabilities, neurotypes, backgrounds, skill levels, and communication styles;
- critique ideas and implementations without demeaning people;
- avoid harassment, intimidation, discrimination, or deliberate exclusion;
- respect privacy and consent, especially when discussing accessibility needs or user research;
- avoid presenting one person's accessibility needs as universal;
- make reasonable efforts to keep discussions understandable and accessible.

## Unacceptable behavior

Harassment, discriminatory abuse, threats, sexual harassment, doxxing, sustained personal attacks, or deliberate disruption are not acceptable.

## Accessibility disagreements

Accessibility needs can conflict. When they do, contributors should document the trade-off, prefer user choice where practical, and seek evidence from affected users rather than treating one preference as universally correct.

## Enforcement

Project maintainers may edit, hide, remove, or reject contributions or participation that violate these expectations, and may temporarily or permanently restrict participation when needed to protect the community.

When possible, concerns should be raised privately with the project maintainer through an available project contact channel.

This code of conduct applies in repository discussions, issues, pull requests, project spaces, and other spaces directly managed by the ORL project.
